# 项目上下文

## Purpose
EPD-nRF5 是一个用于电子纸显示器（E-paper Display）的固件项目，运行在 Nordic nRF5 系列微控制器上。项目主要功能包括：

- **日历显示**：支持公历、中国农历、节气、节假日和工作日调整
- **数字相框**：通过蓝牙传输图片到电子纸显示器显示
- **多设备支持**：支持多种屏幕尺寸（4.2英寸、7.5英寸）和驱动芯片（UC81xx、SSD16xx系列）
- **在线配置**：通过Web界面在线切换屏幕尺寸和驱动类型
- **低功耗设计**：支持睡眠/唤醒功能（NFC/无线充电触发）
- **OTA更新**：支持蓝牙固件升级

## 技术栈
- **编程语言**：C语言（C99标准）
- **微控制器**：Nordic nRF5系列
  - nRF51822 / nRF51802（nRF51系列）
  - nRF52811 / nRF52810（nRF52系列）
- **开发框架**：
  - Nordic SDK 12.3.0（nRF51）
  - Nordic SDK 17.1.0（nRF52）
  - Nordic SoftDevice（BLE协议栈）
- **通信协议**：
  - BLE（蓝牙低功耗）用于数据传输和OTA
  - SPI用于EPD驱动芯片通信
- **前端技术**：
  - Web Bluetooth API（HTML/JavaScript）
  - Canvas API用于图像处理和绘制
- **开发工具**：
  - Keil MDK 5.36或更低版本（推荐）
  - GCC工具链（Makefile构建）
  - MSYS2（Windows平台GUI模拟器）

## 项目约定

### 代码风格
- **命名约定**：
  - 函数名：小写下划线分隔（如 `ble_epd_init`）
  - 类型定义：小写下划线（如 `epd_model_t`）
  - 宏定义：全大写下划线（如 `EPD_CMD_INIT`）
  - 枚举：前缀+大写下划线（如 `DRV_IC_UC8176`）
- **文件组织**：
  - 模块化设计，每个功能模块有独立的 `.c` 和 `.h` 文件
  - 头文件使用 `#ifndef` 保护
  - 公共API在头文件中声明，实现细节在 `.c` 文件中
- **格式化**：
  - 使用4空格缩进
  - 大括号风格：K&R风格（开括号同行）
  - 行长度：建议不超过100字符
- **注释规范**：
  - 使用Doxygen风格注释（`/**@brief`）
  - 函数注释包含参数说明和返回值说明
  - 关键算法和配置需要详细注释

### 架构模式
- **分层架构**：
  1. **硬件抽象层（HAL）**：`EPD/EPD_driver.c` - EPD驱动芯片抽象
  2. **驱动层**：`EPD/UC81xx.c`、`EPD/SSD16xx.c` - 具体驱动实现
  3. **服务层**：`EPD/EPD_service.c` - BLE服务和业务逻辑
  4. **GUI层**：`GUI/GUI.c` - 界面绘制逻辑
  5. **应用层**：`main.c` - 主程序入口和系统初始化
- **驱动抽象**：
  - 使用函数指针结构体实现多态（`epd_driver_t`）
  - 支持运行时切换不同的EPD驱动芯片
  - 统一的驱动接口，便于扩展新驱动
- **事件驱动**：
  - 使用Nordic SDK的调度器（`app_scheduler`）处理异步事件
  - BLE事件通过回调函数处理
  - 定时器事件用于时钟更新和GUI刷新
- **配置管理**：
  - 配置存储在Flash中（使用FDS/FStorage）
  - 支持通过BLE命令动态修改配置
  - 配置包括：引脚映射、屏幕型号、显示模式等

## 领域上下文
- **电子纸显示器（EPD）特性**：
  - 双稳态显示：刷新后保持图像，无需持续供电
  - 刷新速度慢：全屏刷新通常需要2-15秒
  - 支持部分刷新：某些驱动支持局部区域刷新以提高速度
  - 温度敏感：刷新波形（LUT）需要根据温度调整
  - 颜色支持：黑白、三色（黑白红）、四色（黑白红黄）
- **驱动芯片系列**：
  - **UC81xx系列**：UC8159、UC8176、UC8179等
  - **SSD16xx系列**：SSD1619、SSD1677等
  - **JD79xxx系列**：JD79668、JD79665等
- **LUT（Look-Up Table）波形**：
  - 控制EPD刷新时的电压波形
  - 影响显示效果和刷新速度
  - 可从OTP（One-Time Programmable）中读取默认值
  - 支持自定义LUT以优化显示效果
- **农历和节气计算**：
  - 使用 `GUI/Lunar.c` 实现农历转换
  - 支持节气计算和节假日显示
  - 数据存储在代码中，无需外部数据源
- **BLE通信协议**：
  - 自定义EPD服务UUID：`EC5A671C-C1B6-46FB-8D91-28D822367562`
  - 命令通过BLE特征值传输
  - 支持MTU协商以提高传输效率（nRF52支持）
  - 数据分包传输，支持大图像传输

## 重要约束
- **内存限制**：
  - nRF51系列：RAM较小，需要优化内存使用
  - 图像数据需要流式传输，不能全部加载到内存
  - GUI绘制使用回调函数逐行处理，减少内存占用
- **Flash限制**：
  - 需要为SoftDevice预留Flash空间
  - 固件大小受限于芯片Flash容量
  - 配置数据存储在Flash中，需要合理规划存储区域
- **实时性约束**：
  - EPD刷新是阻塞操作，需要等待刷新完成
  - BLE事件处理需要及时响应，避免连接超时
  - 看门狗定时器需要定期喂狗（30秒间隔）
- **功耗约束**：
  - 低功耗设计：无连接时进入深度睡眠
  - 支持NFC或无线充电唤醒
  - 图片模式在显示完成后进入睡眠
  - 日历模式定期唤醒更新显示
- **兼容性约束**：
  - 需要同时支持nRF51和nRF52系列
  - 需要支持多种SoftDevice版本（S110/S112/S130/S132）
  - GUI代码必须保持平台无关性（支持Windows模拟器）
